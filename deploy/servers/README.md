# Local server profiles

Keep machine-specific server notes here **locally only**.

| File | Purpose |
| --- | --- |
| `balemed.md` | Your production VPS connection notes (gitignored — may contain IPs) |
| `*.local.md` | Other local profiles (gitignored) |

Copy from a template or create `balemed.md` with SSH alias, app path, and safety defaults. Do not commit tokens, webhook secrets, or passwords.
